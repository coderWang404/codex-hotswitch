# tools

coderWang 的个人小工具。每个工具放在自己的目录里，互不影响。

## 工具

| 工具 | 说明 |
| --- | --- |
| [codex-hotswitch](codex-hotswitch/) | 不重启 Codex，热切换 cc-switch 里的供应商，并把本机的 Codex 与 cc-switch 配置同步到自己的远程机器 |

## 拿到第一个工具

```bash
git clone https://github.com/coderWang404/tools.git
cd tools/codex-hotswitch
./build-app.sh
```

构建和日常用法写在 [codex-hotswitch/README.md](codex-hotswitch/README.md)。
